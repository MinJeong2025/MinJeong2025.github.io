# MinJeong2025.github.io

This repository contains the source files for my personal academic website built with Quarto.

## Rebuilding the Site

1. Install Quarto.
2. Clone this repository.
3. Open the project in RStudio.
4. Run:

   quarto render

5. The rendered website will be generated in the `docs/` directory.
6. GitHub Pages serves the website from the `docs/` directory on the `main` branch.
